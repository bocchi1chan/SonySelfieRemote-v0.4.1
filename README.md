# SonySelfieRemote v0.4.1.0 — Selfie Monitor Edition

为 Sony A7R II / Sony Camera Remote API 使用场景定制的 Android 自拍监视器。

## 这一版为什么这样设计

核心场景：相机架在三脚架上，手机固定在相机旁边作为取景监视器。用户在手机上按一次“开始自拍”，走到镜头前摆姿势，等待自动拍摄；拍完后手机自动显示刚才的一组照片，确认姿势后再继续下一轮。

## 默认自拍流程

1. 实时取景。
2. 点击大号「开始自拍」。
3. 15 秒倒计时。
4. 自动拍 3 张，每张间隔 1 秒。
5. 三张全部完成后才开始下载 2MP Postview JPEG，避免缩略图下载拖慢连拍节奏。
6. 自动显示本轮照片 5 秒，默认先显示最后一张。
7. 下方缩略图可切换第 1 / 2 / 3 张。
8. 5 秒后自动回到实时取景；也可点大图或「返回取景」立即退出。

## 自拍可调参数

- 倒计时：0 / 5 / 10 / 15 / 20 / 30 秒
- 张数：1 / 2 / 3 张
- 拍摄间隔：0.5 / 1 / 2 秒
- 拍后回看：1 / 3 / 5 / 10 秒 / 一直显示直到点击
- 拍摄过程中再次点击大按钮可请求取消本轮自拍
- App 保持屏幕常亮

## 取景与专业控制

主界面优先保留自拍需要的功能，专业参数默认折叠：

- Live View
- 旋转 90°
- 镜像
- 三分线
- 半按快门 AF
- 点按 Live View 尝试 Touch AF
- 专业控制折叠区：M/A/S/P、快门、光圈、ISO、EV、直方图、斑马纹

所有相机控制都会参考 `getAvailableApiList`。A7R II / Smart Remote Control 实际没有开放的方法不会强行调用。

## 拍后照片

相机会保留完整分辨率原片。本 App 请求 2MP Postview JPEG 用于快速手机回看，并保存到：

`Pictures/SonySelfieRemote`

底部「最近拍摄」仍保留最近 20 张预览图，可点击交给系统相册查看。

## Live View 恢复

某些 Sony 机身在拍照时可能暂时中断 Live View 流。v0.4 增加了自动恢复尝试：本轮拍摄结束后，如果流中断，会再次请求 `startLiveview`。

## 编译

项目包含 GitHub Actions：

1. 将整个项目上传到 GitHub 仓库根目录。
2. 打开 Actions。
3. 运行 `Build Android APK`。
4. 下载 artifact `SonySelfieRemote-v0.4-debug`。
5. 其中的 `app-debug.apk` 即可安装测试。

本工作环境没有 Android SDK，因此这里完成了源码结构/XML/Java 基础语法检查，但没有在本地生成 APK；A7R II 的实际 API 开放情况仍需实机验证。
